# AnimSync Together (native transport)

Adapted from [Caelvanost/AnimSyncTogether](https://github.com/Caelvanost/AnimSyncTogether) at a432ec340f27eea0411e0a7c9eb048ad035c9d31 under MIT (LICENSE). Preserves upstream custom graph input capture, graph variable rules, OAR refresh, GPMA/Helmet Toggle marker cleanup and diagnostic probes. Uses ST_QueryPluginMessaging and authenticated player IDs, not STRPluginMessagingAPI. Install the separately built SKSE DLL and Rules directory on participating clients with matching animation mods. The dedicated server requires only the matching native-messaging Skyrim Together build. Build with the included CMake/vcpkg setup and build_release.bat. Windows runtime compatibility and two-client gameplay remain unverified; the add-on is not yet included in the main release build. Graph state is refreshed periodically; transient events are not replayed to late arrivals. Only explicitly profiled animation inputs are synchronized.

# Native Play menu preview

The Windows client package includes `Interface/startmenu.swf` from `GameFiles/Skyrim/Interface/startmenu.swf`. It uses the STMenuProtocol and STPlayRequested booleans on _root to route Play to the server connection overlay. No separate Play-menu patch is required. Use matching client and server versions. Other main-menu mods can override the bundled SWF; let Skyrim Together win file conflicts to use Play. F2 or Right Ctrl opens the server connection overlay if the original menu is restored.

The adapter reads only primitive boolean Scaleform variables in MainMenu::AdvanceMovie and calls the existing FadeOutAndCall("StartNewGame") when the authenticated new slot is selected. Vanilla intro or alternate-start behavior is preserved; RaceMenu completion triggers the checkpoint workflow. No direct RaceMenu injection or skip-intro behavior is included.

Source references (not binary verification): SKSE64 ScaleformMovie.h/ScaleformValue.h; CommonLibSSE-NG GFxMovie.h, GFxValue.h, MainMenu.h, GFxMovieView.cpp and Offsets.h (AE InvokeNoReturn ID 82665); existing local IMenu.h (AdvanceMovie slot 5). The source-provided SWF's setupMainMenu constructs Continue/New/Load; onMainButtonPress handles NEW; its confirmed New Game branch invokes FadeOutAndCall("StartNewGame"). The native ABI, UI thread/lifetime and in-game behavior have not been verified against either runtime. To troubleshoot, hide or remove the bundled loose SWF (or restore your previous menu) and set ST_DISABLE_NATIVE_MENU=1; use F2 or Right Ctrl to connect. Never use the patched SWF alone with an older client.
The bundled menu replaces Continue/New/Load with Play and restores the other native entries (Quit, Mods, Credits, DLC, Help when enabled by the game). Restored labels are English literals to avoid unresolved localization keys in this asset. The checked-in SWF is the patched user-provided asset. The window-owner message queue and timer pump the UI, runner and lobby transport if Papyrus is inactive; gameplay ECS updates remain on the existing VM path. Browser setup logs identify CEF initialization, renderer creation, receipt and processing of uiReady separately. The overlay requests software rendering on Wine. These changes are source-reviewed only and still need in-game testing.

The CEF uiReady callback publishes an atomic signal; it is consumed by existing game-thread update paths separately from runner tasks. The window owner is determined from the actual window, with a registered wake-up message and timer callback. If the Play handshake remains unavailable after five seconds, open the connection interface once as a recovery path. Engine behavior is source-reviewed only and needs an in-game test.

Compatibility revision: removed Skyrim Together's MainLoop detour (Address Library ID 36564) completely, leaving other mods' trampoline chains alone. Removed menu pumping from the render and inactive-VM callbacks. Browser readiness and lobby actions post a registered Windows message to the game window; the existing timer remains responsible for ongoing transport polling. The normal gameplay VM update hook is unchanged. No engine address or ABI was added. The crash attribution and runtime compatibility remain unverified without a matching local Skyrim installation and debug symbols.

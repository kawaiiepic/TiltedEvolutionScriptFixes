# Native Play menu preview

The Windows client package includes `Interface/startmenu.swf` from `GameFiles/Skyrim/Interface/startmenu.swf`. It uses the STMenuProtocol and STPlayRequested booleans on _root to route Play to the server connection overlay. No separate Play-menu patch is required. Use matching client and server versions. Other main-menu mods can override the bundled SWF; let Skyrim Together win file conflicts to use Play. F2 or Right Ctrl opens the server connection overlay if the original menu is restored.

The adapter reads only primitive boolean Scaleform variables in MainMenu::AdvanceMovie and calls the existing FadeOutAndCall("StartNewGame") when the authenticated new slot is selected. Vanilla intro or alternate-start behavior is preserved; RaceMenu completion triggers the checkpoint workflow. No direct RaceMenu injection or skip-intro behavior is included.

Source references (not binary verification): SKSE64 ScaleformMovie.h/ScaleformValue.h; CommonLibSSE-NG GFxMovie.h, GFxValue.h, MainMenu.h, GFxMovieView.cpp and Offsets.h (AE InvokeNoReturn ID 82665); existing local IMenu.h (AdvanceMovie slot 5). The source-provided SWF's setupMainMenu constructs Continue/New/Load; onMainButtonPress handles NEW; its confirmed New Game branch invokes FadeOutAndCall("StartNewGame"). The native ABI, UI thread/lifetime and in-game behavior have not been verified against either runtime. To troubleshoot, hide or remove the bundled loose SWF (or restore your previous menu) and set ST_DISABLE_NATIVE_MENU=1; use F2 or Right Ctrl to connect. Never use the patched SWF alone with an older client.
